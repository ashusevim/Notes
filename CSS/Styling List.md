# Styling list

- Lists are a common element in web design used to **prevent content from being unorganized**.
- CSS allows you to style lists to **match the design aesthetic** and **improve the readability** of the web page.
- `list-style-position` Has two values:
    1. inside: list markers are **inside** the content box.
    2. outside: list markers are **outside** the content box.
- to remove default list styles: `list-style: none`
