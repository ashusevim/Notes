# Position Property

- <span style="color:rgb(255, 0, 0)">Position property</span> **sets** ==how an element is positioned in a document==. **Top, right, left and bottom** properties **determines** the **final location** of elements.
- `position: relative` Elements are positioned related to the normal position in the document. You can use top, left, right and bottom to move the element.
- `position: absolute` Elements are positioned relative to the closest positioned ancestor (parent), meaning we need to have a parent element with a positioning other than 'static'.
- `position: fixed` **Element will stay in the same place even when the page is scrolled.**
- `position: sticky` **It is treated as relative until it crosses a specified point. Once it reaches that point, it becomes fixed and remains fixed as long as it stays within its containing element.**

### ==Transform, filter or perspective properties can also make an element appear as positioned==
