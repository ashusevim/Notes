# font, text and color properties

- *Font-weight* is used to make font ==bold==.
- **@import URL()** can be used to use external library fonts

---

### text-decoration

- `work-break` is used to break words
- `text-align` is used to bring your text to center
- `letter-spacing` property used to make space between characters

---

### colors

Colors can be represented in many ways:

1. Color keywords (ex. aqua, dark red, blue)
2. Hex Color Code (example. #rrggbb)
3. RGB (ex. `rgb: (33, 4, 2)`), values are between 0 and 255
4. RGBA, here the **extra** `A` **stand for Alpha which specifies the opacity of a color**
5. HSL (**hue, saturation, and lightness**)
