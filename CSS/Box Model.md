## Margin

- The margin is an ==invisible box space around your box==.
- It **pushes** other elements *away from the box*.

### ==Margin collapse: if the margin of two elements is overlapping, then the maximum margin will be applied only once==

## Padding

- Padding sits between the border and the content area and is used to push the content away from the border.
- padding property controls the padding on all sides of an element using these properties:
    1. padding-top
    2. padding-bottom
    3. padding-left
    4. padding-right
