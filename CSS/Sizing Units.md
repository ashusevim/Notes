# Sizing units

- VW - view port width (unit relative to 1% view-port width)
- VH - unit relative to 1% view-port height
- rem - unit relative to **root font size**(html tag)
- em - unit relative to **parent font size**
→ em means "my parent element's font size"
- lh - line height of the element
- rlh - line height of the root element
- min/max - height/width
→ if content is smaller than the maximum height, minimum height will be applied. Similar case with other related properties
