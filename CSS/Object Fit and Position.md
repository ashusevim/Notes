# Object fit and position

The CSS `object-fit` property is used to specify how an `<img>` or `<video>` should be resized to fit its container.

1. using object-fit: cover;
    - if we use cover, the image keeps its aspect radio and fills the given dimention. the image will be clipped to fit.
2. using object-fit: contain;
    - if we use contain, the image keeps its aspect radio, but is resized to fit within the given dimention.

### object-position

The CSS `object-position` property is used to specify how an <img> or <video> should be positioned within its container.
