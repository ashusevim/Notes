# Display Property

### Block-level elements: it always starts on a new line, and the browsers automatically add some space(a margin) before and after the element. (stretches out to left and right as far as it can)

```
- commonly used block elements: <p> and <div>
```

### Inline elements: it does not start on a new line and takes up as much width as necessary.

```
- <span> is an example of inline element
```

---

- `display: inline` Used to convert element inline
- inline property prevents width from having an effect.
- `display: inline` Top and bottom margins and paddings are not respected.
- `display: inline-block` Allows setting a width and height on the element
- `visibility: hidden` used to hide content but space will remain
