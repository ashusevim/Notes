# Shadow and outlines

### Box-shadow

- `box-shadow` Is a popular CSS property that enables designers to add shadow effects around an element's frame.
- `box-shadow: x-offset y-offset blur spread color inset;`

---

### Text-shadow

- `text-shadow` is utilized to give shadows specifically to the text. It can elevate the readability of the text or give it an elegant appearance.
- `text-shadow: h-offset v-offset blur color;`

---

### Outlines

- An outline is a line that is ==drawn around elements==, **outside the borders**
- It's commonly used for **accessibility purposes**, like **highlighting focused elements**.
- `outline: width style color;`
- Outlines don't take up space, they're drowned around the element
- borders can have rounded corners, but outlines generally cannot.
