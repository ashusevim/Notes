# Elementary Operation (Time complexity)

An elementary operation is an operation that takes constant time, regardless of the input size. These are the basic building blocks of algorithms.

Examples:

- Arithmetic operations (+, -, *, /, %)
- Comparison of primitive types (==, !=, <, >, <=, >=)
- Input and output of primitive types
- Assignment operations (=, +=, -=, etc.)
- Memory access operations (array indexing)
- Bitwise operations (&, |, ^, <<, >>)

Approximately 10^8 operations take about 1 second to execute on modern computers, though this varies based on hardware specifications.

Understanding elementary operations is crucial for algorithm analysis, as they form the basis for calculating time complexity (O-notation).
