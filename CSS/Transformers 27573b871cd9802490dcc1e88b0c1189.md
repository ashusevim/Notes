# Transformers

- Transform property applies a 2D or 3D transformation to an element.
- This property allows you to rotate, scale, move, skew etc.
- ex. `transform: rotate(40deg)`
-> item will be rotated to 40 degrees
- 1 turn = 360 degrees
- translate(): moves an element from its current element.
- rotate(): rotate method rotates an element clockwise or counterclockwise.
- scale(): this method increases or descreases the size of an element(parameters: width and height).
- scaleX(): increase or descrease the width of element.
- scaleY(): increase or descrease the height of element.
- skew(): The skew() function tilts an element along the x or y axis
