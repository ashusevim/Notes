# Transition

**tip** - a transition could typically occur when a user hover over an element

- **transition-property:** It specifies the name of css property the transition effect is for.
- **transition-duration:** It specifies how many seconds or milliseconds a transition effect takes to complete.
- **transition-timing-function:** It specifies the speed curve of transition effect.
- **transition-delay**: it specifies when the transition **effect** **will start.**
    - transition-delay **value** is defined in **seconds** or **milliseconds**.
- transition property is a shorthand property used to represent four transition-related longhand properties.
